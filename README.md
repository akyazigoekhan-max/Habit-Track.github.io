
# OpenTasks (TickTick-Style, aber frei & lokal)
**Kein 1:1‑Klon.** Rechtssichere, eigenständige App mit ähnlichem Funktionsumfang.

## Features
- Aufgaben: Titel, Liste, Fälligkeitsdatum, Priorität, Tags, Wiederholung (täglich/wöchentlich)
- Tages- & Wochenlisten (Kalender)
- Individuell einstellbarer Pomodoro-Timer (1–90 min Arbeit, 5–20 min Pause)
- Statistik (Erledigt-% pro Liste)
- Lokale Speicherung (localStorage)
- GH Pages-freundlich (relative base)

## Dev
npm install
npm run dev

## Build
npm run build
# Ordner dist/ auf GitHub Pages veröffentlichen
